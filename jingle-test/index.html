ホールアウトのジングル 試聴

BGMと一緒でないと座りが分からないので、まず「BGMを鳴らす」を押してから聞いてください。
鳴らしているのはゲーム本編と同じ音です（カップ音 → 間 → カード）。

まだ鳴っていません。最初の一回だけ、この画面を触ると音が出せるようになります。

BGMを止めて、カードと同時に鳴らす

コトッ（カップ音）→ 間（俯瞰でラインを見る）→ カード＋ジングル → 静けさ、という流れで鳴ります。
カードが出る合図でBGMが速めに引き、ジングルが終わっても無音のままで、約2.5秒後に「次のホールが始まった」つもりでBGMが戻ります。
BGMは止めずに音量だけ引いているので、戻ったときの出だしは毎回変わります。

    聴きどころ
    ・結果の違い（嬉しい / ふつう / 残念）が、聞いただけで分かるか
    ・5つが別々の曲に聞こえず、同じゲームの音として揃っているか
    ・BGMが引くのは速すぎないか、戻るのは唐突でないか
    ・カードを眺めている間の無音が、落ち着くか・寂しいか
    ・音色がBGM（トライアングルのベース + 単音PSG）から浮いていないか
    ・カップ音の余韻を邪魔していないか
    ・9ホール続けて聞いても うるさくならないか

    このページはゲーム本編と同じ音を、結果別に確かめるためのものです。
